## Compiler

Le document est compatible avec **PDFLaTeX** (compilateur Overleaf par défaut) et
**Biber**. Dans Overleaf, conservez PDFLaTeX et sélectionnez Biber comme outil
bibliographique si ce réglage est proposé. Depuis ce dossier :

```text
pdflatex main.tex
biber main
pdflatex main.tex
pdflatex main.tex
```

évoqués sont limités aux jeux de données synthétiques ou localement préparés décrits
dans la documentation de passation.
